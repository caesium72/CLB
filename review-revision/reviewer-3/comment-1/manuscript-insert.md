## 2. Add to Discussion / Limitations

```latex
The extended validation also exposed three limits. First, the verifier
trusts the self-declared human principal, so an attacker who re-signs a relaxed
mandate with a different key can produce an internally consistent trace; the
binding is only as strong as the identity-resolution trust anchor. Second,
the delegated commitment binds the predicate identifier rather than the
predicate content, so predicate substitution is prevented only if the registry
returns exactly the human-approved configuration. Third, nonce consumption is
scoped to a single facilitator instance, so cross-chain or cross-instance
replay is detectable but not prevented without a shared nonce store. These are
reported as findings rather than hidden by weakening the tests; public-network
and multi-replica evaluation remain necessary.
```
