## How to reproduce

```bash
# from the repository root (Bun 1.4.x on PATH)
bun test packages/service-kit/test/recovery.test.ts   # 9 assertions-based tests
bun run typecheck                                      # tsc --build, exit 0
bun test                                               # full suite, 0 fail
```

The JSON was emitted by a transient harness that imports the same `recovery.ts`
module, wraps `dispatch` to record every command outcome, and calls
`verifyRecoveryEvidence` on the final snapshot of each scenario. The harness is
not part of the repository; the committed unit tests independently reproduce
every fault with fixed timestamps, so evidence hashes are deterministic.

## Interpretation

The machine enforces its properties by *refusing* unsafe commands (they are
recorded as `REJECTED` evidence, not applied) and by *replaying* idempotent
commands (same evidence hash, no second effect). It does not depend on timing:
`TIMEOUT` is an explicit command and reconciliation is an explicit command.
Nothing is inferred from wall-clock expiry inside the state machine.
